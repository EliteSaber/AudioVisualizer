Приложение загружает аудиофайл, показывает спектр в реальном времени и выгружает mp4 с
визуализацией. Столбики расходятся от центральной линии зеркально вверх и вниз.

Настройки применяются сразу: цвет, ширину и форму столбиков, диапазон спектра, атаку и
спад видно на лету. Отдельной кнопки сохранения нет — настройки пишутся при выходе из
окна.

Что умеет:

- открытие аудиофайла и воспроизведение с перемоткой;
- превью спектра во время воспроизведения;
- четыре вкладки настроек: Цвета, Столбики, Спектр и EQ, Экспорт;
- палитра выбора цвета (тон, насыщенность, яркость) с сохранением альфы прежнего цвета;
- след за столбиками, затухающий за заданное время, по умолчанию выключен;
- эквалайзер на 10 полос по ±12 дБ: полосы гнут форму спектра, а по желанию меняют и звук -
  в превью и в аудиодорожке ролика;
- готовые пресеты выгрузки 1080p60, 1080p30 и 720p30, а также произвольные значения;
- выбор кодека видео: H.264 или H.265;
- кодирование на видеокарте, если она есть и умеет выбранный кодек: NVENC, Quick Sync или AMF;
- выгрузка mp4 с оценкой времени, прогрессом и отменой.

Звук ролика берётся из исходника. Спектр считается по сведённому сигналу (моно), для картинки
этого достаточно.

## Скачать

Готовые сборки лежат на странице релизов:
https://github.com/EliteSaber/AudioVisualizer/releases/latest

- `AudioVisualizer-1.0.0-win-x64.exe` — один файл, около 2 МБ, нужен .NET 10 Desktop Runtime;
- `AudioVisualizer-1.0.0-win-x64-selfcontained.zip` — около 68 МБ, ничего доустанавливать
  не надо.

Настройки пишутся рядом с exe.

ffmpeg в комплект не входит, без него выгрузка mp4 невозможна, а прослушивание mp3 и wav
работает и без него. Путь задаётся в настройках на вкладке «Экспорт», иначе ffmpeg ищется в
PATH.

exe не подписан, поэтому Windows может показать предупреждение SmartScreen: «Подробнее» →
«Выполнить».

## Требования

- Windows 10/11 x64;
- .NET 10 Desktop Runtime — чтобы запустить готовую сборку; .NET 10 SDK нужен, только если
  собираете из исходников;
- ffmpeg — нужен не всегда. mp3, wav и aiff декодирует встроенный NAudio вместе с Media
  Foundation, и для них превью работает без ffmpeg. А вот выгрузка mp4 без него
  невозможна, и файлы, которые встроенный декодер не открывает (flac, ogg, opus, m4a,
  wma — если их не берёт Media Foundation), читаются только через ffmpeg.

Путь к ffmpeg ищется так: сначала путь из настроек на вкладке «Экспорт», потом `PATH`.
Кодек H.265 есть не в каждой сборке ffmpeg: если его нет, выгрузка с ним закончится
ошибкой со словами ffmpeg.

Кодирование на видеокарте по умолчанию выключено — включается выбором «Кодирование» на
вкладке «Экспорт». Список заполняется только теми видеокартами, которые нашлись на машине:
ffmpeg запускает настоящую пробу в один кадр, и кодировщик, который в списке есть, но не
работает, в список не попадает. Проба стоит на запуске каждого вендора, поэтому проверка
приходится на момент открытия вкладки, а не на запуск окна. Если карту выбрали, а на
выгрузке она не нашлась, ролик всё равно записывается процессором, и строка состояния об
этом говорит.

Отдельно про NVENC: он есть в списке кодировщиков у большинства сборок ffmpeg, но требует
свежий драйвер (в свежих сборках — 610.00 и новее). При старом драйвере карта в списке не
появится, хотя кодировщик в ffmpeg есть.

## Сборка и запуск

```
dotnet build
dotnet run --project src/AudioVisualizer.App
```

В Visual Studio 2026 — F5. В VS Code — F5 или задачи `build`, `run`, `test`, `clean`.
Тесты запускаются отдельно: `dotnet test`.

Опубликованная сборка одним файлом, framework-dependent x64, все библиотеки внутри exe.

```
dotnet publish src/AudioVisualizer.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:Version=1.0.0
```

Сборка со своим рантаймом, .NET устанавливать не нужно.

```
dotnet publish src/AudioVisualizer.App -c Release -r win-x64 --self-contained true -p:Version=1.0.0
```

Готовый exe лежит в `src\AudioVisualizer.App\bin\Release\net10.0-windows\win-x64\publish`.
Рядом с ним нужен `settings.json` — публикация копирует его сама, иначе при первом запуске
читать будет нечего. В однофайловой сборке программа создаёт файл сама.

## Структура

```
AudioVisualizer.sln
Directory.Build.props              общие настройки компиляции для всех проектов
.editorconfig                      правила оформления кода
LICENSE                            лицензия MIT
docs\logo.png                       логотип для шапки этого файла
docs\releases\                      заметки к релизам: их читает публикация на GitHub
.github\workflows\                 тесты на каждом коммите и сборка релиза по тегу
src\AudioVisualizer.Core\          FFT, декодирование, модель настроек, рендер столбиков, сборка команды экспорта
src\AudioVisualizer.App\           окно, модели представления, панели настроек
src\AudioVisualizer.App\Assets\    иконка приложения и её мастер-PNG 1024×1024
tests\AudioVisualizer.Tests\       тесты обоих проектов
```

`AudioVisualizer.Core` не зависит от интерфейса: расчёт спектра, модель настроек и сборка
команды ffmpeg проверяются тестами вообще без окна.
